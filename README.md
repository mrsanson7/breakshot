# Break Shot

브라우저에서 하는 3D 온라인 당구 게임입니다. 포켓볼(8볼, WPA), 3쿠션(UMB / PBA), 4구(한국 표준)를 지원합니다.
물리와 규칙 판정은 서버가 최종 결정하고(서버 권위), 클라이언트는 같은 시뮬레이션을 재생한 뒤 서버 결과로 위치를 맞춥니다.

## 구조

```
packages/
  shared/   물리(고정 240Hz + 연속 충돌), 규칙(RuleSet), 경기 상태 머신, 설정값(config/*), 네트워크 메시지(zod)
  server/   Node + ws. 방/코드/재접속/샷클락/입력 검증
  client/   Vite + three.js (3D 화면). 연습 모드, 온라인 로비/뱅킹/경기/결과/리플레이
docs/PLAN.md  설계 문서 (모듈, 클라이언트-서버 흐름, 마일스톤)
```

모든 수치는 `packages/shared/src/config/*` 와 `packages/client/src/config.ts` 에만 있습니다.

## 실행

Node 20 이상과 pnpm 9 이상이 필요합니다.

```bash
pnpm install
pnpm dev          # 서버 :8787 + 클라이언트 :5173 (Vite가 /ws 를 서버로 프록시)
```

브라우저에서 http://localhost:5173 을 엽니다. 같은 네트워크의 다른 기기에서는 `http://<내 IP>:5173` 으로 접속하면 됩니다.

| 명령 | 내용 |
| --- | --- |
| `pnpm test` | Vitest 전체 (전체 88) |
| `pnpm typecheck` | 세 패키지 타입 검사 |
| `pnpm build` | 클라이언트 dist + 서버 단일 번들 `packages/server/dist/index.js` |
| `pnpm start` | 빌드된 서버 실행. `STATIC_DIR=packages/client/dist` 를 주면 클라이언트도 같이 서빙 |

### Docker

```bash
docker build -t breakshot .
docker run -p 8787:8787 breakshot     # http://localhost:8787
```

이미지 하나가 정적 파일과 WebSocket(`/ws`)을 같이 서빙하고 `/health` 로 헬스체크합니다.
(작업 환경에 Docker 데몬이 없어 이미지 빌드는 직접 확인하지 못했습니다. 같은 번들을 Docker 없이 실행하는 것은 확인했습니다.)

### 인터넷으로 친구와 하기

**방법 1. Render에 올리기 (추천, 내 PC를 꺼도 됨)**

1. https://render.com 에 GitHub 계정으로 가입합니다.
2. **New → Blueprint** 를 누르고 이 저장소를 고른 뒤 **Apply** 를 누릅니다. 저장소의 `render.yaml` 이 무료 웹 서비스 하나를 만듭니다.
3. 5~10분 뒤 생기는 `https://breakshot-xxxx.onrender.com` 주소를 친구에게 보내면 됩니다. 이후 `main` 에 푸시하면 자동으로 다시 배포됩니다.

무료 요금제는 15분 동안 아무도 접속하지 않으면 잠들고, 다음 접속 때 깨어나는 데 1분 정도 걸립니다. 서버가 잠들거나 다시 배포되면 진행 중인 방은 사라집니다.

**방법 2. 내 PC에서 임시 주소 만들기 (PC를 켜 둔 동안만)**

```bash
pnpm serve                                        # 빌드 후 :8787 하나로 게임 전체를 서빙
cloudflared tunnel --url http://localhost:8787    # 다른 터미널에서. https://….trycloudflare.com 주소가 나옴
```

`cloudflared` 는 https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/ 에서 설치합니다. 주소는 실행할 때마다 바뀝니다.
`pnpm dev`(5173) 대신 `pnpm serve` 를 쓰는 이유는 화면과 서버가 한 포트에 있어야 터널 하나로 다 통하기 때문입니다.

## 조작

- 시점: 🎥(큐 뒤) / 🗺️(위) 버튼으로 바꿉니다. 큐 뒤 시점에서는 공이 굴러가는 동안 카메라가 테이블 전체가 보이도록 올라갑니다.
- 큐 뒤 시점: 테이블을 누른 채 좌우로 끌면 조준이 돌아가고, 파워 바를 끌었다 놓으면 샷.
- 위 시점 + 마우스: 조준은 마우스 이동, 클릭한 채 뒤로 당기면 파워, 놓으면 샷. 우측 파워 바를 끌어서 쏴도 됩니다.
- 키보드: ←/→ 미세 조준(Shift는 크게), W/A/S/D 당점, Esc 취소.
- 위 시점 + 터치: 테이블을 끌어 조준, ⟲/⟳ 버튼으로 미세 조준(누르고 있으면 반복), 아래 파워 바를 끌었다 놓으면 샷.
- 프리볼: 수구를 끌어서 놓습니다.
- 항공 보기: 🛩️ 항공 버튼을 누르면 카메라가 바로 위로 올라가 테이블 전체를 내려다봅니다. 큐 뒤 시점의 조작(좌우로 끌어 조준, 파워 바)은 그대로입니다. 공이 굴러가는 동안에는 항상 위에서 봅니다. 켜고 끈 상태는 브라우저에 저장됩니다.
- 연습 도우미(연습 모드만): 〰️ 궤적은 지금 조준·당점·큐 각도로 수구가 실제 물리대로 갈 길(쿠션 6번까지)을, 📐 시스템은 3쿠션에서 파이브 앤 하프(출발 − 1쿠션 = 3쿠션) 숫자와 선을 보여 줍니다. 세기는 마지막으로 친 세기를 씁니다.
- 큐 각도: Q(세우기)/E(눕히기) 키나 큐 그림을 위아래로 끌어 0~60°로 조절합니다. 세운 큐로 옆을 치면 공이 휘어집니다(마세).
- 게임 화면과 첫 화면의 **❓ 조작법** 버튼을 누르면 컴퓨터와 스마트폰 조작법을 볼 수 있습니다.
- 🔊 버튼은 효과음, 🎵 버튼은 배경음악을 따로 켜고 끕니다. 배경음악은 파일 없이 브라우저에서 바로 만들어 연주합니다(`MUSIC` 설정은 `packages/client/src/config.ts`).

## 가정 (코드 주석에도 있음)

- 8볼은 콜샷 없이 진행합니다. 브레이크 반칙은 상대 프리볼, 브레이크 때 8번이 들어가면 풋 스팟에 다시 놓습니다. 그룹은 브레이크 이후 처음 합법적으로 넣은 공으로 정합니다.
- 3쿠션 UMB: 이퀄라이징 이닝은 설정으로 켜고 끕니다. 브레이크 샷은 빨간 공을 먼저 맞혀야 합니다.
- 3쿠션 PBA: 세트제, 뱅크샷(첫 공 전에 쿠션 1회 이상) 2점.
- 4구: 방장은 흰 공, 상대는 노란 공입니다. 빨간 공 두 개를 맞히면 1점이고, 파울 감점은 기본 0점(설정 가능)입니다.
- 4구 시작 배치: 빨간 공은 풋 스팟과 센터 스팟, 상대 공은 헤드 스팟입니다.
- 선공(초구) 정하기: 방 설정에서 랜덤, 뱅킹, 방장 먼저, 참가자 먼저 중에 고릅니다. 연습 모드는 플레이어1/2/랜덤.
- PBA 초구 배치: 9개 자리 중 초구자 공 1~3, 상대 공 4~6, 빨간 공 7~9에서 하나씩 고릅니다. 추첨(경기마다 한 번 정해 모든 세트에 같게)이나 지정(예: 2-4-8, 3-5-8) 중 고릅니다. PBA 초구는 어느 공을 먼저 맞혀도 됩니다.
- 뱅킹(선공 결정): 각자 자기 공을 풋 쿠션까지 보내고, 헤드 쿠션에 더 가깝게 멈춘 쪽이 선공합니다. 동점이면 다시 합니다.
- 큐를 세우면 아래로 향하는 힘은 바닥이 받아내고 공은 수평 성분(cos α)만큼만 나갑니다. 점프샷은 없습니다. 회전은 큐 방향과 당점으로 계산하므로 세운 큐에 옆 당점을 주면 회전축이 기울어 천과의 마찰로 휘어집니다.
- 조준선은 직선으로만 보여 주므로 마세 샷의 휘어짐은 표시되지 않습니다.
- 재접속 시 현재 상태는 그대로 이어지지만, 그 전에 오간 샷 기록(경기 중 "다시 보기")은 비어 있을 수 있습니다.
- 상대가 접속이 끊기면 샷클락이 멈추고, 60초가 지나면 남은 쪽이 몰수승을 요청하거나 더 기다릴 수 있습니다.

## 확인 필요 목록

코드에는 `TODO(확인 필요)` 로 표시되어 있습니다.

- **최신 PBA 규정 확인 필요**: 세트 점수(15/마지막 11), 선승 세트 수, 뱅크샷 점수와 조건, 샷클락 35초 등 `config/rules.ts` 의 PBA 값 전체.
- UMB 브레이크 배치: 수구가 헤드 스팟에서 떨어진 거리 0.182 m (`config/layouts.ts`).
- 중대 테이블 크기 2448 × 1224 mm (제조사마다 다름).
- 4구 공 지름: 사양은 61.5 mm이지만 국내 4구장은 65.5 mm를 많이 씁니다.
- 4구 파울 감점: 기본 0점이지만 많은 구장이 1점을 감점합니다.
- 4구 시작 배치: 구장마다 다릅니다.
- 포켓 관련 값: 턱 길이, 낙구 판정 깊이, 구멍 반지름과 위치 (`config/tables.ts`).
- 레일과 쿠션 폭 (화면 표시용), 다이아몬드 위치.
- 큐 각도 최대값 60° (`maxCueElevationDeg`). 실제 마세는 80° 가까이 세우지만 점프가 없는 이 모델에서는 60°까지만 둡니다.
- **PBA 초구 배치 9개 자리의 정확한 좌표** (`config/layouts.ts` 의 `pbaSpots`). 공식 그림을 찾지 못해 2-4-8이 UMB 배치와 같도록 추정했습니다.
- 파이브 앤 하프: 코너 근처 보정과 당점/세기 보정은 넣지 않았습니다 (`FIVE_AND_HALF`, `packages/client/src/config.ts`).
- 캐롬 천 구름 저항 0.009 (포켓볼 천보다 잘 굴러간다고 가정).
